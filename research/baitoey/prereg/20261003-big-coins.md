# Pre-registration: trade only the biggest coins? (Baitoey, 2026-10-03)

Written and committed before any run. Not edited after results exist; results go to
`results/baitoey/20261003-big-coins/` and a report committed under `research/baitoey/results/`.

## Question

The first test-account run (2 Oct, 15:00 UTC) bought PUMP, WLD, AAVE, HBAR, SUI and AVAX: the six strongest
7/14-day movers of the 29 Roostoo coins, most of them small. Would the momentum models do better if they could only
pick from the largest coins? We have no point-in-time market capitalisation, so "largest" means the highest trailing
30-day traded value (quote volume), the same measure the universe is already built from (top 30, then cut to the
coins Roostoo lists; about 20 coins at the median date, 29 now). A fixed list of the coins that are large today would
look ahead (we know which ones survived), so it is not used.

## Runs

At each daily universe date, keep only the top N of the usual Roostoo universe by trailing 30-day quote volume
(hourly quote volume summed over the 720 hours up to that date). Nothing else changes.

| Run | Model | N |
|---|---|---|
| V0 / E0 | `baitoey_vt_mom` / `pol_switch_vt_tl_e20v45` | all (registered runs, read from the registry) |
| V10 / V15 | `baitoey_vt_mom` | 10 / 15 |
| E10 / E15 | `pol_switch_vt_tl_e20v45` | 10 / 15 |

Scored with `score_model` like `--score`, not registered (the leaderboard is untouched). The benchmark strategies
that set the bars are read from the cache built on the usual universe, so the bars are the same as in the base runs
(checked: the per-window STRICT bars must equal those of the base run). Script: `research/baitoey/big_coins.py`.

## Verdict (fixed now), per model

- A run is **better** if it passes the hard gates, HEADLINE_RET >= base - 0.01, and either the worst 14-day R_liq
  improves by at least 2 points or CS_HIT rises by at least 0.02.
- A run is **worse** if it fails a hard gate or HEADLINE_RET < base - 0.03 (the team margin).
- Otherwise **no clear difference**.
- **Propose to the team** only if both N = 10 and N = 15 are better for that model (no picking the best N).
- Report-only: HEADLINE_RET without the post-holdout windows, CS_HIT, hit rates in strong / mild falls and rises and
  in volatile windows, weighted median and mean R_liq, worst R_liq, the two real-round replays, fees.

## Known limits, stated before running

- Traded value is not market share; a coin can trade a lot while being small (ZEC is third now).
- The post-holdout windows (Jul-Sep 2026) are in the pool and were already seen.
- The round starts 2026-10-04 12:00 UTC; nothing here changes the launch. A positive result would go through the
  team rule for upgrades (pre-written rule plus three days of paper) like any other change.
- Spreads come from one Roostoo snapshot, which shows small coins at about 0.01% half-spread, so trading costs are
  barely modelled differently for big and small coins.
