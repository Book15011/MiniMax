## Pre-registered choice rule

Written and committed before any walk-forward skill was computed. Not to be edited after results exist.

- **Dates.** T* = 2026-10-03 16:00 UTC. Holdout H = T* − 56 days = 2026-08-08 16:00 UTC. Nothing may use a
  window whose outcome period (t0, t0 + 14d] passes H.
- **Test dates D:** every 7 days from 2022-07-01 16:00 UTC up to H − 14 days (last D = 2026-07-25 16:00 UTC).
- **No leakage.** At each D only pool_D = {t0 : t0 + 14d ≤ D} is used. Percentiles are recomputed on pool_D, and
  K = 25 lookalikes are picked for the state at D. D is skipped if 25 cannot be picked.
- **Score.** The empirical CRPS of the 25 lookalikes' outcomes against the realised outcome at D, separately for
  each of Y1..Y8.
- **Baselines.**
  - (a) all of pool_D
  - (b) the 25 most recent non-overlapping windows in pool_D
  - (c) 25 random windows from pool_D, drawn with the same spacing rules as the lookalike pick (≥ 14 days apart,
    ≤ 3 per 90-day span), mean CRPS over 50 draws
- **Skill.** Skill = 1 − ΣCRPS_lookalike / ΣCRPS_baseline over the test dates of a period, per Y. The headline is
  the mean of the eight per-Y skills. 90% intervals come from a moving-block bootstrap: blocks of 4 consecutive
  test dates, 2,000 resamples, seed 20261003.
- **Periods.** SCREEN = test dates 2022-07-01 … 2024-06-30. CONFIRM = test dates 2024-07-01 … 2026-07-25.
- **Candidates:** CORE, CORE+POSITIONING, CORE+MACRO, CORE+CALENDAR, CORE+POSITIONING+MACRO, ALL.
  - The leave-one-CORE-group-out variants are diagnostics only and can never be chosen.
  - A variant with a group that has no data is not a candidate.
- **Rule.** Choose the candidate with the highest mean skill vs baseline (a) in SCREEN (ties go to the earlier
  candidate in the list above). Keep it only if its CONFIRM mean skill vs (a) is > 0 AND ≥ CORE's CONFIRM mean
  skill; otherwise use CORE.
- **If CORE's CONFIRM mean skill vs (a) is ≤ 0,** the report states plainly that lookalikes are not predictive.
- **Final set:** the chosen variant, the full pool (t0 + 14d ≤ H), the state at `--asof`, and K = 25. Sensitivity:
  K = 15 and K = 40, and each group of the chosen variant dropped in turn, reported as Jaccard overlap with the
  main set.
- **Fixed in advance, not tuned:** the similarity (mid-rank percentiles within the reference pool; group-weighted
  squared percentile distance with w_g = 1 / number of active groups), the greedy spacing rules, K, the horizon,
  the baselines and this rule.
